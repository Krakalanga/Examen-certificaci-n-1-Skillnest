Primer intento de examen de certificación final curso Python-Fullstack, el diseño de los templates los realice con bootstrap 5.

⚙️ INSTALACION Y EJECUCIÓN DEL PROYECTO

1. clonar el repositorio: git clone https://github.com/Krakalanga/Examen-certificaci-n-1
2. cd Examen-certificaci-n-1-Skillnest
3. crear entorno: python -m venv .venv
4. activar entorno: venv\Scripts\activate
5. instalar dependencias: pip install -r requirements.txt
6. ejecutar app: python server.py

📂 Estructura del proyecto

El proyecto está organizado siguiendo el patrón de arquitectura Modelo-Vista-Controlador (MVC), tal como se solicitó en las instrucciones del examen.
